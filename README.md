# Netflix Content Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Titles dataset to understand content distribution, genre trends, country contributions, release patterns, and relationships between content features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Cleaning
- Removed duplicate records
- Handled missing values
- Converted date columns
- Performed feature engineering

## Feature Engineering
- Content Age
- Cast Count
- Director Count
- Country Count
- Genre Count
- Rating Groups
- Weekend Indicator

## Visualizations
- Movies vs TV Shows
- Content Added Over Time
- Top Countries
- Genre Analysis
- Director Analysis
- Correlation Heatmap
- Cast vs Genre Analysis
- Duration vs Cast Analysis

## Key Findings
- Movies dominate Netflix's catalog.
- Content additions increased significantly after 2015.
- The United States and India are major content contributors.
- Drama and International Movies are among the most common genres.
- Most numerical features exhibit weak correlations.
- Multi-genre titles tend to have slightly larger casts.
